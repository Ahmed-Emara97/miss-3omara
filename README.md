# الموقع الأكاديمي — نورا حمدي فياض
### نسخة إعادة التصميم الكاملة (Premium Academic Profile)

موقع Static بالكامل (HTML + CSS + JS، من غير Backend ولا استضافة مدفوعة).

## الملفات
- `index.html` — بنية الصفحة الكاملة
- `style.css` — نظام تصميم متكامل (ألوان، خطوط، بطاقات، تايم لاين، الوضع الليلي)
- `script.js` — كل التفاعلات (سكرول سباي، حركات الظهور، الفلاتر، العدّادات، الوضع الليلي)

## إيه اللي اتغيّر جذريًا عن النسخة اللي فاتت
هي مش تعديل شكلي — دي إعادة بناء كاملة لهوية الموقع:

- **هوية بصرية جديدة كليًا:** كحلي غامق + دهبي/برونزي بدل التيل والأوكر، بإحساس "مجلة أكاديمية" مش "لطيف بسيط"
- **خطوط بتفرق فعليًا:** Source Serif 4 للعناوين (وزن وحجم مختلفين لكل مستوى) + Inter للنصوص، بدل ما كل حاجة نفس الوزن
- **بطاقات حقيقية بعمق:** كل قسم (الأبحاث، الشهادات، الإنجازات، التواصل) بقى بطاقات منفصلة بظل وحدود وhover state، مش صفوف مسطحة
- **Timeline بصري** للتعليم بخط رأسي ونقاط ومحتوى داخل بطاقات
- **بنية معلومات جديدة:** Hero → عن الباحثة → التعليم → الخبرة → الأبحاث (بفلاتر) → الشهادات → الإنجازات → التواصل — كل قسم له غرض واضح
- **فلترة تفاعلية** لقائمة الأبحاث (الكل / سيمبوزيوم / وبينار / ورش)
- **صورة شخصية** في إطار premium (مش دائرة بسيطة) + تعليق توضيحي جنبها
- **إحصائيات متحركة** في الهيرو (سنين الخبرة، عدد المؤتمرات...)
- **وضع ليلي/نهاري** بنظام ألوان مستقل بالكامل مش مجرد عكس الألوان
- **تجاوب حقيقي** اتفحص يدويًا على 1440 / 1280 / 1024 / 900 / 768 / 480 / 390 / 360 بكسل، ومفيش أي overflow أفقي في أي مقاس

## إضافة صورة شخصية حقيقية
حطي ملف الصورة في نفس فولدر الموقع وسمّيه بالظبط: `photo.jpg`
هتظهر تلقائيًا مكان الإطار اللي فيه "NF".

## الرفع على GitHub Pages
1. اعملي Repository جديد على github.com.
2. ارفعي `index.html`, `style.css`, `script.js` في الجذر.
3. Settings → Pages → Source: branch `main`, مجلد `/root`.
4. اللينك هيبقى: `https://username.github.io/repo-name/`

## الرفع على Cloudflare Pages / Netlify / Vercel
كلهم بيقبلوا نفس الطريقة: ارفعي الثلاث ملفات كـ "static site" من غير أي build command. الموقع مش محتاج أي backend أو قاعدة بيانات.

## ملاحظة
مفيش رابط Google Scholar أو ORCID في السيرة الأصلية، فسبت مكانه ملاحظة قصيرة وواضحة في قسم التواصل بدل ما أختلق رابط. أول ما يبقى عندك الرابط، ضيفيه كـ `<a>` جنب الإيميل في `index.html` داخل `.contact-list`.
